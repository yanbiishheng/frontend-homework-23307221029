# 作业三图片目录

当前源码使用 CSS 渐变作为图片兜底，因此图片缺失时页面仍可正常显示。

如果以后找到原图片，请把文件复制到此目录，并保持以下文件名：

```text
cos-1.jpg
cos-2.jpg
cos-3.jpg
cos-4.jpg
reg-bg.jpg
reg-error.png
login-input2.png
login-input3.png
login-input4.png
```
