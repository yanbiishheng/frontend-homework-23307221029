🔍 常用选择器示例（每种一个例子）

以下选择器均在页面中有效，配合实际元素说明。

1. 元素选择器 (element) input { ... } — 选中所有 input 元素，如上方输入框
2. 类选择器 (class) .field-label { ... } — 选中所有 class="field-label" 的标签区域
3. ID 选择器 (id) #username { ... } — 精确选中 id="username" 的用户名输入框
4. 属性选择器 (attribute) input[type="date"] { ... } — 选中所有日期输入框（证件有效期、出生日期）
5. 伪类选择器 (pseudo-class) input:focus { ... } — 输入框获得焦点时样式（如蓝色外圈）
6. 伪元素选择器 (pseudo-element) .hint::before { content: "ⓘ "; } — 可在提示文字前加图标，本页未加但语法有效
7. 后代选择器 (descendant) .field-control input { ... } — 选中 .field-control 内部的所有 input
8. 子代选择器 (child) .inline-group > label { ... } — 选中 .inline-group 的直接子元素 label
9. 相邻兄弟选择器 (adjacent sibling) input + .hint { ... } — 选中紧跟在 input 后面的 .hint 元素
10. 通用兄弟选择器 (general sibling) input ~ .hint { ... } — 选中同一父级下 input 之后的所有 .hint
